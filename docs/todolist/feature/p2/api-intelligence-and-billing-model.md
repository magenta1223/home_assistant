# 공식 모델 API 지능 제공과 과금 모델

## 목표

개인·로컬 설치에 맞춘 현재의 Codex CLI 로그인 기반 지식 분석과, 외부 고객에게 제공할 제품의
기본 런타임 계약을 분리한다. 고성능 지식 주입·기억 재구성은 공식 모델 API로 수행하고, 고객의
비용 부담 방식(BYOK)과 운영자가 비용을 부담하는 관리형 구독·크레딧 방식을 명확히 비교·결정한다.

현재 가족용 로컬 제품의 동작에는 필요하지 않다. 실제 외부 고객 제공과 비용 부담 모델을 결정할
때 재개하며, 그 전에는 공식 API·결제·고객별 key 보관을 선제 구현하지 않는다.

## 원칙

- 현재 로컬 Codex CLI 로그인은 개인 사용의 선택지로 남길 수 있으나, 고객 제품의 백엔드가 고객의
  Codex 권한을 위임받는 기본 계약으로 사용하지 않는다.
- 일반 ChatGPT 로그인이나 앱 연결은 신원 확인 또는 대화 진입점이 될 수 있지만, 백엔드 모델 실행의
  고객별 Codex 권한 위임 해결책으로 간주하지 않는다.
- 모델 호출 주체, 비용 부담 주체, 고객 원문·권한의 처리 경계, 감사 책임을 호출마다 식별 가능하게 한다.
- 특정 클라우드, 프레임워크, 단일 모델 공급자에 고정하지 않고 공식 API와 교체 가능한 제품 계약을 우선한다.

## 단계

1. 로컬 CLI, BYOK, 관리형 API의 지원 범위·신뢰 경계·장단점과 전환 조건을 ADR로 비교한다.
2. 제품 기본 모델 실행 계약(API 인증, 모델 선택, 요청·응답 최소 데이터, 실패 분류)을 정의한다.
3. BYOK의 키 연결·암호화 보관 또는 고객 측 실행 대안, 키 회전·폐기·마스킹·접근 감사를 결정한다.
4. 관리형 옵션의 구독·크레딧·사용량 계량, 요청별 비용 추정·집계·한도 초과 동작을 정의한다.
5. 지식 주입과 기억 재구성의 원문 전달 범위, 저장 기간, 권한 전파, 삭제·감사 요구를 데이터 흐름별로 확정한다.
6. API 장애·제한·비용 한도 초과 시의 대기, 재시도, 사용자 안내와 안전한 중단 기준을 정한다.

## 완료 조건

- 외부 고객 제품의 기본 지능 실행이 공식 모델 API 계약으로 정의되고, 로컬 Codex CLI와 역할이 구분된다.
- BYOK와 관리형 옵션 각각의 책임, 가격 단위, 사용량 계량, 비용 한도와 초과 처리 방식이 문서화된다.
- 고객 원문, 접근 권한, 감사 기록, API 키 비밀이 수집부터 실행·보관·삭제까지 보호되는 경계가 정해진다.
- 요청별 actor/tenant, 모델 호출, 비용·한도 판정, 실패가 추적 가능하며 키나 원문이 로그에 노출되지 않는다.

## 제외 범위

- 특정 공급자·클라우드의 결제 연동 또는 키 저장 구현
- ChatGPT 로그인만으로 백엔드 모델 권한을 위임하는 기능
- 기존 개인·로컬 설치의 Codex CLI 흐름 제거
